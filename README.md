# Pricing Comparison Table

A simple HTML pricing comparison table that presents different plans and their features in a clear, accessible layout.

## Roadmap

This project is based on the [Pricing Comparison Table project](https://roadmap.sh/projects/pricing-comparison-table) from roadmap.sh.

## Features

- Semantic HTML structure
- Responsive viewport configuration
- Accessible table headings with `scope` attributes
- Comparison of storage, projects, and support for each plan
- Navigation links for the main pages

## Project Structure

```text
.
├── pricing_table.html
└── README.md
```

## Getting Started

1. Clone or download this repository.
2. Open `pricing_table.html` in a web browser.
3. Review the available plans and their features.

No build tools or dependencies are required.
